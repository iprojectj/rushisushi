For Rūshī Sushi, the user prioritizes Kalangfy for PIX payments and has access to UTMify for sales attribution.

**Why:** the user explicitly chose Kalangfy as the priority while rebuilding the lost backend.

**How to apply:** default new payments to Kalangfy and keep UTMify available for purchase tracking. Do not switch providers without the user's direction.
